# MYLO
MYLO is a piece of software dedicated to the development of neural-networks and aims to be the one-stop neural-network development solution, with tools for analysing models and datasets, training and optimising them and even implementing a visual model editor. 

The app is supposed to be flexible and be usable both in local networks and external ones, the processing client being made to be easily deployable, allowing you to have a powerful computer handle the actual model processing and interfacing it from a lightweight web-interface accessible anywhere. 

[Web interface repo](https://github.com/M-Y-L-O/WebInterface)
